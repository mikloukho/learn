# Литкод на Go, по темам

Не подряд, а темами — так возвращается навык распознавания паттернов.
Порядок: массивы → строки → хеш-таблицы → два указателя → списки → деревья.

## Как работать
1. Открываешь файл темы, решаешь функции сверху вниз.
2. `go test ./leetcode/arrays/` — тесты уже написаны, сейчас красные.
3. Красный → зелёный. Тесты покрывают и краевые случаи: пустой вход,
   один элемент, всё одинаковое. На литкоде именно они и валят.
4. Не видишь подхода за 15 минут — открывай разбор, разбирай до конца,
   через два дня решай заново с нуля. Сидеть час бесполезно: ты не
   вспоминаешь паттерн, а изобретаешь его заново.

## Приёмы (веди этот список сам, дописывай после каждой задачи)
- Мапа как множество: `map[T]struct{}`, значение занимает 0 байт.
- Мапа "видел значение → индекс" за один проход (Two Sum).
- Бегущий минимум/максимум (Best Time to Buy and Sell Stock).
- Два указателя навстречу (палиндром, разворот).
- Два указателя в одну сторону, медленный/быстрый (Move Zeroes, дубли).
- Идти С КОНЦА, когда запись затирает непрочитанное (Merge Sorted Array).
- Стек на слайсе: push = append, pop = s[len(s)-1] + s = s[:len(s)-1].
- Фиктивная голова + хвостовой указатель при построении списка.

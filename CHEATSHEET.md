## Типы данных

### Числа
```go
int      // 64 бита на современных машинах, но размер зависит от платформы
int8/16/32/64, uint8/16/32/64   // когда размер важен явно
float64  // дробные. float32 — только если реально экономишь память
byte     // = uint8, псевдоним. Для сырых данных
rune     // = int32, псевдоним. Одна кодовая точка Unicode
```

Отличие от PHP: **типы не смешиваются молча**. `int + float64` не
скомпилируется, нужно `float64(x) + y`. Даже `int` и `int64` — разные типы.
Приведение всегда явное.

Подвох: деление целых даёт целое. `7 / 2 == 3`. Нужен `float64(7) / 2`.

### Строки
```go
s := "привет"
len(s)                        // 12 — БАЙТЫ, не символы
utf8.RuneCountInString(s)     // 6 — символы
s[0]                          // byte (208), а не 'п'
for i, r := range s { }       // r это rune, i — байтовый индекс, прыгает
```

Строка **неизменяема**: `s[0] = 'X'` не компилируется. Менять — через
`[]byte` (только ASCII) или `[]rune` (безопасно), потом обратно в строку.

Конкатенация в цикле через `+=` аллоцирует новую строку каждый раз.
Много кусков — `strings.Builder`.

### Bool
```go
var ok bool   // false
```
Нет приведения к числу вообще: `int(ok)` запрещено, `ok + 1` тоже.
Тернарного оператора в языке нет — только `if`.

### Нулевые значения
Переменная без инициализации не «пустая», а **обнулённая**:
```
int, float   -> 0
string       -> ""
bool         -> false
указатель, слайс, мапа, канал, функция, интерфейс -> nil
структура    -> все поля обнулены
```
Состояния «не инициализировано» не существует, поэтому и null не нужен.

### Массив vs слайс
```go
var a [3]int      // МАССИВ: фиксированная длина, ЗНАЧЕНИЕ, копируется целиком
s := []int{1,2,3} // СЛАЙС: ссылка на массив, три поля (ptr, len, cap)
```
Массивы сравнимы через `==`, слайсы — нет (только с `nil`).
В PHP оба были одним `array` — здесь это принципиально разные вещи.

### Мапа
```go
m := map[string]int{}
v := m["нет"]        // 0, а не ошибка
v, ok := m["нет"]    // ok == false — так отличают отсутствие от нуля
```
Ссылочный тип. Запись в `nil`-мапу — паника, чтение — нормально.
Порядок обхода **намеренно случайный**. Нужен порядок — сортируй ключи.

### Указатели
```go
p := &user      // взять адрес
*p              // разыменовать
```
В PHP объекты всегда по ссылке, скаляры по значению — решать было нечего.
Здесь решаешь сам на каждой функции.
Арифметики указателей нет (в отличие от C).

## Ловушки, на которых я уже попадался
<!-- пиши сюда каждый раз, когда что-то не сработало как ожидал -->

- `len("привет")` это 12, а не 6 — байты, не символы.
- Неиспользуемая переменная и неиспользуемый импорт — ОШИБКА компиляции,
  а не предупреждение.
- `if` без фигурных скобок не компилируется, даже на одну строку.
- `i++` — инструкция, а не выражение: `x := i++` запрещено.
- Точки с запятой не ставятся, `gofmt` их удаляет.

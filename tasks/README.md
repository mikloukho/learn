# Задачи по Go

Всё внутри `.go` файлов: условие, инсайты и вопросы с собеса — комментариями
над плейсхолдерами. Отдельных task.md нет, между файлами прыгать не надо.

- `NN_тема/solution.go` — заготовки с `panic("TODO")`. Пишешь ты.
- `NN_тема/buggy/` — рабочий на вид код с подложенным багом. В шапке файла
  тикет в формулировке саппорта, где баг — не сказано. Ищешь сам, потом
  пишешь тест, доказывающий фикс.
- Всё про конкурентность гоняешь через `go test -race`.
- `go vet` запускай ПОСЛЕ того, как поискал глазами — он называет часть багов прямо.
